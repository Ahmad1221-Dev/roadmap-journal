# AI Prompt Templates & Guardrails

## 1. The Hint-Only Prompt

> "I am working on [feature/bug]. Here is my current code: [code]. Do not give me the solution or write the code for me. Instead, give me a conceptual hint or ask a guiding question to help me figure it out."

## 2. The Error Explainer

> "I am getting this error: [error message]. Explain what this error means in plain English and why Node/Git throws it, rather than just pasting the fix."

## 3. Code Review & Best Practices

> "Review this snippet of code for readability and potential edge cases: [code]. Point out any bad habits or logical flaws."

## 4. Concept Breakdown

> "Explain how [concept, e.g., git branching or flexbox] works using a real-world analogy and a short code example."
