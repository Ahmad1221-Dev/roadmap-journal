### Terminal Commands Learned

1. `pwd` — Prints the current working directory path.
2. `ls -la` — Lists all files in the current folder, including hidden files.
3. `mkdir -p` — Creates a new directory (and parent directories if needed).
4. `touch` — Creates a new empty file.
5. `history` — Shows a list of previously run terminal commands.

### VS Code Shortcuts I Will Use

1. `Ctrl + Shift + P` — Opens the Command Palette to quickly search settings and actions.
2. `Ctrl + ~` (or ``Ctrl + ` ``) — Toggles the integrated terminal open and closed.
3. `Alt + Up/Down Arrow` — Moves the current line of code up or down.
